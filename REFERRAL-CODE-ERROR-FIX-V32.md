## Fixed
- Resolved `function gen_random_bytes(integer) does not exist` by replacing referral-code generation with a database sequence.
- New member referral codes now auto-generate as `RA-REF-000001`, `RA-REF-000002`, etc.

- The connected Royal Alliance Supabase project's `public.prepare_member_insert()` was updated and the sequence was created.

## How referral codes work
- `Referral code (optional)` in Add New Member is for entering the *existing referrer's code*, not choosing the new member's own code.
- Each new member's own code is generated by the database and should be shown in the member record/details after creation.
- To make the next new code start at `RA-REF-000001` on a brand-new/empty sequence: `select setval('public.referral_code_seq', 1, false);`
- For a custom next number N: `select setval('public.referral_code_seq', N, false);` Replace N with the desired positive integer. Do not reset this on a live database unless checking existing codes first, as it can cause unique-code conflicts.
